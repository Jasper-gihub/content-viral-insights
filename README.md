# B 站「数据分析」赛道 · 内容爆款规律分析

用公开数据回答一个内容运营的核心问题：**在这个赛道里，什么样的内容能火？** 结论不是"要努力"，而是"个人创作者该做什么、不该做什么"。

## 为什么这个项目值得讲

- **内容运营岗的硬通货是"内容判断力"**：能说清"为什么这个标题会火"，比"我发过内容"值钱得多
- 项目把"感觉"变成了"可验证的特征"：7 个标题特征 × lift（爆款组出现率 ÷ 普通组出现率），并诚实标注了小样本局限
- 发现了**赛道结构事实**（头部 62.5% 是机构课程合集）——这类"先看清战场"的判断，正是运营岗要的能力

## 数据

| 项目 | 说明 |
|---|---|
| 来源 | B 站公开搜索接口（会话 cookie + 重试退避，避免反爬拦截） |
| 关键词 | 数据分析 求职 / 数据分析 转行 / SQL 学习 / Python 数据分析 / 数据分析师 入门 |
| 规模 | 1,000 条 → 去重 806 → 有效（播放 > 0）**801 条** |
| 字段 | 标题 / UP 主 / 播放 / 点赞 / 收藏 / 弹幕 / 时长 / 发布时间 |
| **口径** | 搜索按综合排序返回，头部被过度代表；要求规律分析限定「单集内容型」（≤30 分钟，446 条）；爆款 = 播放 P90 |

## 方法

1. **时长分层**：单集内容型（≤30 分钟）/ 长视频 / 合集课程（>4 小时）——防止机构课程污染"内容型"结论
2. **定义爆款**：用 P90 而不是均值（长尾极重：中位数 4,382，均值 31.6 万）
3. **标题特征 lift**：7 个规则特征分别算 爆款组 vs 普通组的出现率之比
4. **时长与互动率**：分桶对比播放中位数、点赞率、收藏率

## 关键结论

1. **赛道头部被机构课程占据**：Top 10% 播放中 62.5% 是 >4 小时合集 → 个人创作者应避开"体系化课程"战场
2. **最强爆款特征：第一人称叙事（lift 4.25）**——标题含「我 / 亲测 / 血泪」的视频出现在爆款组的概率是普通组的 4 倍
3. **反直觉**：标题含数字（lift 0.52）、疑问词（lift 0.24）与**低**播放相关——"10 个技巧""怎么学 SQL"是红海
4. **时长甜蜜区 3–10 分钟**（播放中位数 4,174），但爆款与普通的时长差异很小 → 时长不是决定因素
5. **爆款的点赞率是普通的 1.7 倍**（2.5% vs 1.5%）→ 爆款不是运气，是内容本身更让人想点赞

## 局限

- 搜索接口按综合排序返回，**不能**推断全站爆款率；高播放视频被过度代表
- 爆款组仅 45 条，特征结论为**方向性**；未控制 UP 主粉丝量（无法区分内容因素与账号因素）
- 标题特征用规则匹配（非语义分析）；单平台、单赛道、2026-10 时间窗
